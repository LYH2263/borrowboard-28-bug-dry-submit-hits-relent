# Borrowboard · 邻里借用

上架 → 借出通过 → 干跑预览 → 提交归还；单物件同时仅一笔在借，含逾期判定。

| 服务 | 端口 |
| --- | --- |
| 前端 | 5400 |
| API | 10400 |

## 归还干跑

看板右栏勾选在借笔 → **干跑预览**列出将回到可借栏的 title（左右分栏与顶细条集合不变）→ **提交**才整单改为 `returned`。

- `POST /api/returns/dry-run {loan_ids:[…]}` → `{batch_id, titles, loans, counts_after}`；只写 preview 批次，不动分栏。
- `POST /api/returns/commit {batch_id}` → 整单一个事务落库；`409 stale_batch` 表示名单已漂移。

**拍板：整单失败，不按提交瞬间重算。** 干跑后若有人先归还、同一物又借出通过、或逾期扫正在跑，提交时名单里任一笔不再在借 → 整单 409，分栏、物主栏、顶细条一律不动，前端重新干跑。理由：重算会把用户没预览过的在借笔悄悄带走，分栏与顶细条会跳到从未预览过的状态；整单失败保证预览即所得。

配套不变量：

- 顶细条与分栏同源同事务：禁止顶细条可借已加、在借栏还挂着。
- 未在借笔不得被带走（SQL 层 `AND status='active'` 兜底）。
- 二次提交同一批次 → 原样回放，已还的笔不再写第二遍。
- 提交中途失败 → 整体回滚，分栏/物主栏/顶细条一起回到提交前，批次可重试。

0-1：`deposit` / `damage_note` / `neighbor_rating`。
